# UDYAM AI — AIML & LightGBM Demand Forecasting Integration Guide

| `udyam_recommendations.json`| Authoritative procurement recommendations | Base demand, uplifts, stock, POs, and priority levels |
| `__init__.py` | Python package exports | Seamless import into FastAPI backend and Copilot |

## 4. Strict Planning Language Rule

Procurement quantities generated by the AIML pipeline are decision-support planning recommendations rather than guaranteed purchase orders.

> **MANDATORY PHRASING:**  
> All user-facing interfaces (backend API, LLM responses, Copilot chat, and frontend banners) must use:  
> **"Review procurement for approximately X kg additional [Product] stock."**  
> *(Never use "Buy exactly X kg" or "Purchase X kg immediately".)*

Example for Besan:
```
"Review procurement for approximately 266 kg additional Besan stock."
```

## 5. FastAPI Backend Endpoints

Exposed in `backend/main.py` under `/api/aiml/*`:

| Endpoint | Method | Params | Description |
| :--- | :--- | :--- | :--- |
| `/api/aiml/forecast` | `GET` | `product_id` (optional) | Returns 7-day daily forecasts for one or all products |
| `/api/aiml/recommendations` | `GET` | None | Returns all 6 procurement recommendations |
| `/api/aiml/product/{product_id}` | `GET` | `product_id` (path) | Combined forecast, recommendation & planning statement |
| `/api/aiml/insights/{product_id}` | `GET` | `product_id` (path) | Alias for `/api/aiml/product/{product_id}` |
| `/api/aiml/summary` | `GET` | None | Overall engine status, product counts, and portfolio totals |

All endpoints support aliases: `besan`, `prod_besan`, `ghee`, `dry fruits`, `atta`, `rice`, `sugar`.

## 6. AI Copilot (Ollama + Llama 3.2 3B) Grounding

The AI Copilot routes queries mentioning commodities (`besan`, `ghee`, etc.) or forecasting keywords directly to AIML tools:

1. `get_aiml_product_insight`: Injected into prompt context when specific commodity is asked.
2. `get_aiml_recommendations`: Injected during reorder or shortage queries.
3. Zero Numeric Hallucination: The LLM explains and synthesizes the prediction using grounded tool data without inventing numbers.
4. Prompt instruction enforces the mandatory planning language format.

## 7. Frontend Integration

1. **`src/services/api.ts`**:
   - `apiService.getAIMLForecast(productId?)`
   - `apiService.getAIMLRecommendations()`
   - `apiService.getAIMLProductInsight(productId)`
   - `apiService.getAIMLSummary()`
   - Complete offline fallback protection via `FALLBACK_AIML_RECOMMENDATIONS`.

2. **`src/pages/DemandForecast.tsx`**:
   - Engine toggle between `LightGBM Demand Regressor (7-Day)` and `Auto Components (30-Day)`.
   - Dynamic commodity selector (Besan, Ghee, Dry Fruits, Atta, Rice, Sugar).
   - 4-Stage multi-signal fusion pipeline visualization.
   - Authoritative planning guidance card with exact quotation.
   - Recharts 7-day line chart comparing base ML demand vs signal-adjusted demand.
   - Full 6-commodity portfolio table with priority badges and "Create PO" action.

3. **`src/pages/Inventory.tsx`**:
   - Dual-pillar switcher: `Active Warehouse SKUs` | `AIML Commodity Procurement (LightGBM)`.
   - Renders 6 responsive commodity cards displaying base demand, market and festival uplifts, adjusted demand, stock levels, and planning recommendations.
   - Action buttons issue requisitions with toast feedback.
